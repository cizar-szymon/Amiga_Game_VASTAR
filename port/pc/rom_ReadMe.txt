VASTAR - ROMs / ROM-y
=====================

EN: Put the arcade's ROMs here: the MAME set "vastar" (vastar.zip, or
the files unpacked from it: c_*.rom, e_*.rom, tbp24s10.*). They are not
included with the game - use your own copy of the arcade's ROMs.
Another place can be given with the option -rompath DIR.

PL: Tu wgraj ROM-y automatu: zestaw MAME "vastar" (vastar.zip albo
rozpakowane z niego pliki: c_*.rom, e_*.rom, tbp24s10.*). Nie sa
dolaczone do gry - potrzebna wlasna kopia ROM-ow automatu.
Inne miejsce mozna podac w opcji -rompath KATALOG.
